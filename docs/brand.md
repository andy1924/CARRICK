# Carrick visual identity

Carrick's mark is a geometric **C** with consistent beveled corners and a single blue connector. The open form represents the connection between field work and its schedule activity. The symbol uses solid vector shapes, remains legible at favicon size, and does not depend on a raster image or an external font.

## Assets

- [Mark](../apps/web/brand/carrick-mark.svg) for the app, favicon, and compact use.
- [Logo](../apps/web/brand/carrick-logo.svg) for documentation and larger placements.
- [Field-to-schedule illustration](../apps/web/brand/field-to-schedule.svg) for the landing page hero. Pipework connects to a schedule display in a faint technical line drawing; it is decorative and stays behind the page content.

The mark is original SVG artwork in this repository. Keep its proportions and clear space; do not stretch it or add shadows. The full logo uses a broadly available sans-serif font for its wordmark, while the symbol remains fully vector geometry.

## Colors

| Role | Color |
| --- | --- |
| Slate | `#172B4D` |
| White | `#FFFFFF` |
| Connector blue | `#2856D8` |

The interface uses these sparingly with neutral backgrounds, visible borders, and task-focused text. Status color always appears with a written label.

Primary interface actions use `#2856D8`. The website and workspace use a system sans-serif font stack. See [website design](design/website-redesign.md) for the visual hierarchy and research references.
