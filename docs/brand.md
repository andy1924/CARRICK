# Carrick visual identity

Carrick's mark is a structural **C** with two internal progress lines and one endpoint. It represents field observations being linked to a planned activity. The shape remains legible at favicon size and does not depend on a raster image or an external font.

## Assets

- [Mark](../apps/web/brand/carrick-mark.svg) for the app, favicon, and compact use.
- [Logo](../apps/web/brand/carrick-logo.svg) for documentation and larger placements.

The mark is original SVG artwork in this repository. Keep its proportions and clear space; do not stretch it or add shadows. The full logo uses a broadly available sans-serif font for its wordmark, while the symbol remains fully vector geometry.

## Colors

| Role | Color |
| --- | --- |
| Deep green | `#17352F` |
| Warm white | `#F5F2EA` |
| Copper | `#D77A50` |

The interface uses these sparingly with neutral backgrounds, visible borders, and task-focused text. Status color always appears with a written label.
